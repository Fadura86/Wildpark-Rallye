# Wildpark-Rallye Dülmen – App

Interaktive Web-App zur Wildpark-Rallye im Wildpark Dülmen (20 Stationen, ca. 4 km).
Sie ersetzt unterwegs den Papierausdruck: Fragen, Antwortkästchen und Bilder entsprechen der Original-Broschüre.

- Antworten werden automatisch auf dem Gerät gespeichert (localStorage).
- Der Lösungssatz füllt sich aus den nummerierten Kästchen der Stationen.
- Seite „Meine Antworten“: Übersicht zum Screenshot bzw. Übertragen auf den Ausdruck.
- Funktioniert nach dem ersten Laden auch offline (Service Worker).

## Veröffentlichen (GitHub Pages)

Settings → Pages → Source „Deploy from a branch“ → Branch `main`, Ordner `/ (root)`.
Danach ist die App unter `https://fadura86.github.io/Wildpark-Rallye/` erreichbar.

## Hinweis

Inoffizielle, private digitale Fassung. Texte und Bilder stammen aus der Broschüre
„Wildpark-Rallye“ (Stand 17.01.2022) des Biologischen Zentrums Kreis Coesfeld, Lüdinghausen.
